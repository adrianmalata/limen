## 2. What Pi 1.5.1 and the bridge allow

Pi:
- `--tools/-t` "Comma-separated allowlist of tool names or patterns (*) to enable; Keeps MCP tools unless an entry starts
  with mcp__; Only +name/-name entries add to or remove from the defaults" (pi:`dist/cli/args.js:313-315`, parsed
  `:114-125`); `--no-tools` (`:311`), `--exclude-tools` (`:316`). Built-in names: `read`, `bash`, `powershell`, `edit`,
  `write`, `grep`, `find`, `ls` (pi:`dist/core/tools/index.js:19-28`); defaults `["read", "bash", "edit", "write"]`
  (pi:`dist/core/settings-manager.js:35`), or a settings layer's `defaultTools` (`:1071-1076`), which an explicit list
  replaces (pi:`dist/core/sdk.js:148-157`).
- The allowlist also filters extension tools: registered tools pass `_isAllowedTool` (pi:`dist/core/agent-session.js:1197-1203`,
  `:2971-2981`), so a role's list must name `finish`, and an `--extension` package's tools drop unless named.
- `--no-skills` (pi:`dist/cli/args.js:188-189`, `:323`): only `--skill` paths load (pi:`dist/core/resource-loader.js:439-441`);
  `--skill <path>` (`args.js:166-168`, `:322`). The skills block is listed only when `read` or `bash` is declared
  (pi:`dist/core/system-prompt.js:101-108`). Per run, a `before_agent_start` handler may filter
  `systemPromptOptions.skills` (`evidence/engine-sources/pi-1.5.1.md:114`).
- `--no-extensions` also turns off the built-in `mcp`, `codemode` and `tool-search` extensions
  (`evidence/engine-sources/pi-1.5.1.md:58`; pi:`dist/core/resource-loader.js:424-425`), so jobs have no MCP tools.

Bridge (bridge-ev §3, `:103-140`; §4 `:157`; §1 `:32`, `:46`):
- Pi's current tools, replayed from the transcript's `system` entries, are Claude's only tools, as
  `mcp__custom-tools__<name>`; `tools: []`, the built-ins and an always-denied list (`Agent`, `Task`, `Skill`,
  `ToolSearch`, `AskUserQuestion`, …) in `disallowedTools`, `allowedTools: ["mcp__custom-tools__*"]`,
  `bypassPermissions` (`:106-113`). "A restricted Pi tool list … reaches Claude Code exactly" (`:120`).
- Caveat: zero Pi tools → the bridge drops `tools: []` and Claude Code's own Read/Write/Edit/Bash come back (`:122`).
- Subagent: `Agent` and `Task` always denied; Pi's `tool_call` sees only Pi names (`:124`).
- Skills: "the bridge passes no SDK `skills` option, so the CLI defaults apply, and it denies the `Skill` tool. Pi's
  skills list reaches the model only through the append" (`:157`), cut out of Pi's prompt (`:32`, `:46`).
- Open (`:140`): whether the seat CLI still puts built-in or deferred-tool definitions into the context despite
  `--tools ""`; that is step 4.3.
