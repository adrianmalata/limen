The picture is a local architecture map, not a committed file: a gitignored Markdown dataset (default `<root>/.limen/picture/`). It never lands on a tip, and it gates no merge or spawn. Rules for the dataset live in the package's `templates/picture/CONTRACT.md`. `limen picture build --strict` is its check: it reads the dataset with the tickets and the board, writes no page, and exits 1 on an error. `limen picture serve` serves this project's job activity on 127.0.0.1, at `/activity.json` and `/events`.

A lane move leaves map sources that cite the old path: run `grep -rln --include='*.md' 'FNNN-' <root>/.limen/picture` and fix each source, or start the keeper, which fixes map sources in the map itself. Before a direct commit of a ticket or board change on main, run `limen picture build --strict`: it reads the working-tree tickets and exits 1 on an error.
